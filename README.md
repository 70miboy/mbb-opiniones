# mbb-opiniones

Opiniones **públicas** de Mercado Libre que [My Baby Boom](https://www.mybabyboom.com.ar)
muestra en las páginas de producto de su tienda.

`opiniones.json` lo genera un script del negocio y se publica acá para que el navegador
de quien visita la tienda pueda pedirlo. Se publica como repositorio público porque
GitHub Pages lo sirve por CDN y permite el pedido desde otro dominio.

**No editar a mano.** Cada publicación reemplaza el archivo entero.

De cada opinión se publica sólo lo que Mercado Libre ya muestra en público: estrellas,
título, texto, mes y año, y las fotos que subió quien la escribió. **Nunca** se publica
quién compró, ni su contacto, ni el número de orden.
